# 地雷版（VRCX-jirai）功能在哪里，和本分支有什么区别

查阅时间：2026-09-20。本文根据 `FuLuTang/VRCX-jirai` 的 README、导航定义、路由与个人资料组件核对。**说明原软件的用法，不代表这些功能已经移植到 VRCX_stalk。** 菜单文字会随安装版本及语言不同而变化。

原 Jirai README 目前写明不再维护。这是原作者对该项目维护状态的说明，不应据此推断整个 VRCX 上游的实际维护状态。使用旧客户端前，先自行检查版本、登录兼容性和设置；不要把旧版前端文件直接覆盖到新版 Insights 中。

## 先分清三种程序

| 程序 | 本文中的含义 |
| --- | --- |
| VRCX | 官方原项目，提供好友动态、游戏日志、图表等基础功能 |
| VRCX-jirai / 地雷 Edition | FuLuTang 的修改版，包含下文的扩展 |
| VRCX_stalk / VRCX Insights v3 | 当前仓库，新增显式启动的本地分析缓存与共同游玩回顾；不是完整 Jirai 移植 |

**在当前 Insights 中反复恢复默认导航，也不会出现尚未移植的 Jirai 功能。** 当前能直接使用的新入口是正常侧边栏中的“共同游玩回顾”。

## 原 Jirai 的入口与操作

### 共同实例查询 / 双人关系

入口在 **侧边栏 → 图表 → 共同实例 / 双人关系**，源代码路由为 `charts-two-person`（`/charts/two-person`）。

打开后选择两位玩家，再查看共同实例记录和提供的筛选选项。记录可包括共同停留、房间信息、进入先后、自己是否在场等。数据不足时无法还原所有历史。

原版一些标签根据进入时间先后作启发式分类。**这些标签不是两个人实际关系、聊天或“约好一起玩”的证据。** 房间创建者也不必然当时仍在场。

当前 Insights 的对应能力是“共同游玩回顾 → 看分组”：建立包含两人的本地分组，看组内重叠时长；它不包含 Jirai 那套关系推测标签，也不补推隐藏位置。

### 好友关系网、手动连线与非好友节点

入口在 **图表 → 共同好友关系网**，路由 `charts-mutual`。原 Jirai 的图表工具栏有手动关系管理按钮（链条图标），以及显示/隐藏非好友节点的按钮。

先载入图谱；需要补充自己的本地标注时进入手动关系管理，选择两人并保存。显示非好友节点需要有该版本可用的数据或已经配置的追踪对象。

手动添加的线是你自己的标注，不是服务端确认的好友关系。没有连线也不一定表示两人不是好友，可能只是没有权限或没有记录。

当前 fork 保留上游自带的关系图能力；**Jirai 的手动关系、推荐关系与追踪非好友增强未移植**。不要把两个版本中同名的“关系网”视为功能完全相同。

### 个人简介 Bio 差异

在原 Jirai 打开玩家个人资料，查看简介及简介历史区域。该版本用差异形式展示已有简介变化：删除与新增内容有不同标记；README 描述了对一天内多次变化的合并。

必须先有旧简介与新简介记录。刚导入空数据库、只有最新简介时，不能凭空生成过去的变化。

当前 Insights：**共同游玩回顾 → 选中玩家 → 左侧日志 → 更改 Bio**，显示源日志的修改前后文本。这里不是 Jirai 的彩色逐字 Diff，也没有宣称完成其 24 小时合并算法。

### 交流密度 / 关系时间轴

入口在 **图表 → 关系时间轴 / 交流密度时间轴**，路由 `charts-timeline`（`/charts/timeline`）。选择界面支持的对象和时间范围，查看其基于记录汇总的时间分布。

它依赖观测覆盖，不应把“未记到”解释为“没有发生”。当前 Insights 没有完整移植这个专用时间轴页面。

### 灯色分布

打开 **自己或好友的个人资料 → 灯色分布** 标签页。已核对的源组件仅在当前对象是自己或好友时加入这个标签；查看任意陌生人时不一定有此入口。

原 Jirai README 说明其计算结合状态变更与上下线历史，排除离线时段。缺失历史会影响结果，因此不是完整生活作息记录。

当前 Insights 有状态变更日志，但 **没有移植灯色占比图**。查看日志并不等于已经实现这个统计功能。

### 非好友追踪

原 Jirai README 给出的入口有两个：主页好友列表旁的 **追踪非好友** 列，或打开玩家资料，在 **“…”菜单 → 追踪** 中添加；也支持输入用户 ID。

按原文说明，该功能记录的主要是简介及灯色变更。先核对软件的设置和提示，再决定是否使用；它不能保证获取隐藏实例或未公开活动。

当前 Insights **没有非好友远程追踪功能**。“共同在场的人”中出现一个非好友，只表示已有本地游戏日志记录过同场，不表示软件开始追踪此人。

### 多账号共同登录

原 Jirai 在登录页支持选择主要账号与次要账号；登录后的左下角视图切换器用于各账号或合并视图。

这和在一个普通 VRCX 窗口中先退出再登录另一个账号不是一回事。当前 Insights 按账号与源路径分开缓存，但 **没有移植 Jirai 的多账号同时在线、聚合视图**。

### 信息补全与快捷搜索

原 Jirai README 还介绍了资料补全、简介存档、最近遇到的人/最近世界、简介搜索等扩展。部分资料补全会访问 VRChat API，不等于本地离线扫描。

当前 Insights 的姓名联想只查询已经生成的缓存目录；它没有暗中调用原 Jirai 的批量信息补全。

### 自动跟随

原 Jirai README 将这项功能划掉，并标明未实现且不再计划。**不要将其当作可用功能寻找，也不要把当前 Insights 的手动查询误写成自动跟随。**

## 原 Jirai 的新功能为什么没出现在侧边栏

原 README 给出的处理方法是 **右键侧边栏 → 自定义导航栏 → 恢复默认**。这会改变用户自己的导航布局，操作前留意已有自定义配置。

这个方法只适用于安装包本来就带有相关功能、只是布局没显示的情况。首先确认启动的是 Jirai，而不是官方 VRCX 或当前 VRCX Insights。当前 fork 没有移植的页面不会因为重置导航而出现。

## Home Group 与隐私设置

原 Jirai README 描述了加入其 Home Group 的行为。不同版本的开关和实现可能不同，使用原客户端前应检查设置及账号群组状态。**当前 Insights 的本地分析缓存不会加入任何 Group，也没有移植那段自动加入逻辑。**

任何版本中，已有日志、当前公开状态和推断结果都要区分。不要绕过他人明确设置的隐私边界，也不要将启发式标签当成真实关系结论。
